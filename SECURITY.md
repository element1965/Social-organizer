# Security policy

## Supported version

Security fixes are made on the current `main` branch.

## Reporting a vulnerability

On GitHub, go to **Security** and choose **Report a vulnerability** to open a private report. If that button is not there yet, open an issue that only asks for a private contact, without any details of the problem. <!-- contact: update when the team e-mail exists -->

Include the affected component and version or commit, the conditions required, concise reproduction steps, the observed behavior and impact, and any relevant redacted logs or screenshots. Use test accounts and redact credentials and personal data.

Keep the report private while maintainers investigate and coordinate disclosure. Social Organizer has no bug bounty program.
