# Покрытие редизайном функций `main`

Каждая функция и экран текущего приложения (ветка `main`, ноябрь 2026) и где она живёт в редизайне.
Обозначения: **есть** — спроектировано и есть в макетах v2 или в screens.md; **слито** — функция остаётся, но
переезжает в другой экран; **убрано** — сознательно удаляется, причина рядом; **вопрос** — нужно решение владельца
продукта (список вопросов в конце).

## Платформа и инфраструктура (без изменений, проверить после редизайна)

Telegram Mini App (тема, BackButton, haptics, safe-area), Capacitor (deep links, нативный push, системный share,
камера для сканера — новое), web push (VAPID), Gun.js бэкап графа (используется и для кэша координат), i18n на
28 языков, PWA/манифест, healthcheck.

## Что убирается целиком

RetiredFeaturePage и маршруты matches/skills/needs; CloudBackground; MilestonesCard и AcquaintanceCard как карточки;
InviteBlock, InvitePopup, ShareSheet с семью брендовыми кнопками; график роста сети; бейдж «День N»; скрытая плавающая
кнопка ChatAssistant; цепочка модалок создания сбора; подсказка про мышь, «GoodWill Net», английская легенда;
демо-режим (`demo-token`, `demoData.ts`) — уже не работает.

## Решения (приняты 2026-11-08)

| № | Вопрос | Решение |
|---|---|---|
| 1 | Лендинг и вариант `arvut` | Лендинг по `hui.html` — отдельная задача после приложения. `arvut` остаётся как языковой вариант нового лендинга, если по нему есть трафик (проверить перед работой); иначе убрать и не поддерживать RTL в первой версии |
| 2 | Вехи | Строки в ленте Круга плюс один короткий лист-поздравление при первом рукопожатии. Отдельной карточки нет; «10 связей» уже видно в пути к просьбе |
| 3 | Видеоинструкции | Убрать из приложения до новых записей; переснять после релиза редизайна. Интро и пустые состояния закрывают потребность |
| 4 | Сбор без цели | Убрать: цель обязательна (минимум 10 $). «Установить цель» и `amount = null` в новых сборах не создаются; старые без цели показываются как «цель не задана», автор задаёт её при первом открытии |
| 5 | Статус BLOCKED | Заблокировать сбор может **только администратор**, выбрав одну из причин. Участник видит «Сбор приостановлен», без кнопки участия и чата; автор видит причину и контакт поддержки. Новые процедуры `collection.block({ id, reason })` и `collection.unblock`, админские. Причины (черновик, уточнить): «Жалобы участников», «Подозрение на мошенничество», «Нарушение правил», «По просьбе автора» |
| 6 | Голос ассистента | Один голос по умолчанию; выбор — в настройках самого Помощника, не в общих |
| 7 | Тема | Три варианта одним сегментом: Авто (по умолчанию), Светлая, Тёмная |
| 8 | Напоминания о циклах | Один тумблер «Циклы сборов» (за 3 дня и о старте) |
| 9 | Связать аккаунт кодом | Убрать с экранов (и «Есть код из Telegram-бота» со входа); API оставить. Вернуть одной строкой в «О приложении», если аналитика покажет использование |
| 10 | Игнор-лист | API оставить, в интерфейс не выносить. «Убрать из круга» закрывает сценарий |
| 11 | Валюты | Только $ везде; API не трогать |
| 12 | Типы контактов | Все десять как варианты «Ещё контакт»; по умолчанию телефон, почта, Telegram. VK и TikTok убрать, если в прод-данных пусто (проверить запросом) |
| 13 | Telegram-тема | От Telegram берём только светлую/тёмную схему; цвета — свои токены |
