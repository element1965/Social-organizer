## Сделать
1. Приглашение `/invite/:token`: аватар пригласившего, «Олег Ким зовёт вас в свой круг», одна фраза, пилюли
   «N человек в сети» и «может помочь на N $» (`invite.getByToken`), кнопки входа по устройству; для вошедшего по
   чужой ссылке — «Мы знакомы». Нерабочая ссылка — один экран с «Открыть приложение» / «Войти».
2. Вход: картинка круга 240, «Войдите или создайте аккаунт», кнопки по устройству (Android: Google, Telegram;
   iPhone: Apple, Google, Telegram; остальное: Google, Apple, Telegram), «Войти по почте» текстом, юридическая строка.
   Почта: одно поле и «Получить код» (`auth.requestEmailCode`); код: шесть ячеек с автоотправкой
   (`auth.verifyEmailCode`), таймер повтора, «Изменить адрес». Пароль — только по `/login?mode=password`;
   «Код из Telegram-бота» с экрана убрать (API остаётся). Пути Google/Apple (deep link) и Telegram не ломать.
3. Интро: три кадра с `netFigure(0..2)`, сеть на одном месте, «Пропустить» в углу, одна кнопка «Дальше» / «Понятно»;
   `user.completeOnboarding`; повторно доступно из Помощи.
4. Минимальное участие: вопрос первым, 1 $ по умолчанию, пресеты и свободный ввод, тихая плашка о заявке
   пригласившему, «В круг» → пустой Круг.
5. `components/figures/*`: React-компоненты фигур на токенах, пропсы `step`/`depth`, `prefers-reduced-motion`.
