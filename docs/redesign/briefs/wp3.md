# WP3 — 3D-граф: производительность и визуал

Ветка `redesign-wp3-graph` от `redesign`. Не зависит от WP1, можно стартовать сразу. Сдача — локальный мердж в `redesign` после ревью (ветка в GitHub не пушится). В `main` не пушить.
Думать и отвечать по-русски; код, комментарии и коммиты — по-английски.

**Принцип (решение владельца продукта, 2026-11-09):** граф не пишется с нуля. Берём существующий `NetworkGraph`
(`react-force-graph-3d` + three.js) и приводим его к виду последних макетов (`mockups/v2/circle-a.html`,
`desktop.html` №1): правки точечные, движок и API для старых экранов сохраняются. Приёмка — сверка дизайна с
макетом, поиск багов и проверка отображения в 3D-пространстве (вращение, глубина, зум, подписи, путь).

## Сделать (по ux-audit §8)
1. Общие геометрии и материалы по уровню детализации и глубине; одна геометрия колец онлайна.
2. Подписи только у N ближайших к камере узлов и у подсвеченного пути; 3-е кольцо без подписей.
3. Один тик анимации для пульсов; пересчёт LOD раз в 5–10 кадров.
4. Кэш координат (IndexedDB через `@so/gun-backup` или `localStorage`), симуляция только для новых узлов.
5. Пауза рендера в покое; возобновление по pointer/touch и смене данных.
6. `setPixelRatio(min(dpr, 2))`; прямые линии для 2–3 кольца, кривые только у пути.
7. Палитра из токенов через пропсы (цвета сцены и `care`), центральный узел — знак приложения, подписи Manrope
   с обводкой цвета сцены, приглушение всего кроме пути при фокусе; убрать «GoodWill Net», подсказку про мышь,
   английскую легенду; тултип по тапу в стиле карточки.
8. Жесты: один палец — вращение, два — зум/панорама, инерция; `prefers-reduced-motion` отключает дрейф и пульс.
9. Пропсы: `onNodeTap`, `highlightPath`, `hiddenRings`, `focusOnMe` (ref), `theme`; кнопки +, −, «вписать» —
   через ref-методы, рисует их WP2.
