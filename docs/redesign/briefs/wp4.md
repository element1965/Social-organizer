## Сделать
1. Просьба: доступ при 5 в 1-м кольце и 10 в сети (готово в 4a: `collection.askAccess`, проверка в `create`); сумма
   не ограничена, при превышении «Сеть может помочь» — тихое предупреждение под полем; форма с суммой, типом (разовая / каждые 28 дней), обязательной целью, ссылкой на
   чат в любом мессенджере (валидация `https://`), инлайн-ошибки, единственный лист для сумм > 10 000; свой открытый
   сбор строкой над формой; лист «Как создать чат?».
2. Сбор участника: шапка (путь, автор, шкала, одна строка о закрытии), карточка суммы с предзаполненным минимальным
   участием, «Участвовать», состояние обсуждения с «Открыть чат сбора», «Изменить», «Отказаться» с листом; новый цикл
   регулярного сбора с тёплой плашкой и «Подтвердить N $» / «Другая сумма»; закрытый сбор.
3. Сбор автора: ссылка на чат с карандашом, «Поделиться сбором» и QR (лист с кодом и «Скачать для печати»), список
   участников с колонкой «Переведено», «Закрыть сбор» с листом подтверждения, удаление присоединившегося по ссылке
   человека из круга одним действием.
4. Публичная страница `/sos/:id` по макету №6: аватар, «Анне нужна помощь», строка типа и давности, карточка суммы,
   плашка «Вы станете частью круга», одна кнопка «Присоединиться», строка о способах входа.
5. BLOCKED: плашка «Сбор приостановлен» у участника, причина и «Написать в поддержку» у автора, «Приостановить /
   Возобновить» с листом причин у админа.
6. Открытые (из Профиля): карточки открытых сборов. Удалить `CreateCollectionPage` и старый `CollectionPage`.
