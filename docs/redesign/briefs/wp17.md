# WP17 — Понятность: один словарь, одно объяснение, меньше лишних нажатий

Ветка `redesign-clarity` от `redesign`, worktree `../so-clarity`. Сдача — локальный коммит; мердж делает
координатор. Ничего не пушить. Код, комментарии и коммиты — по-английски.

## Читать перед стартом
- `docs/redesign/audit-2026-11-09.md` §2 — список проблем с файлами.
- `docs/redesign/ux-audit.md` §5 (словарь), `docs/redesign/screens.md`, макеты `docs/redesign/mockups/v2/*.html`
  (экран сбора — линейка этапов).
- `packages/i18n/locales/en.json`, `ru.json`; проверка `pnpm i18n:check` (`scripts/i18n-check.mjs`).

## Решения координатора (не пересматривать)
1. **Просьба и Сбор.** «Просьба» — только название таба и формы (действие «попросить»). То, что появляется после
   отправки, везде называется «сбор»: кнопка формы «Открыть сбор», дальше «Ваш сбор», в ленте «Ваш сбор · 60 из
   120 $», «Сбор закрыт». В en: таб/форма «Ask», объект «collection». В уведомлениях и Telegram-боте — тот же словарь;
   Emergency/Regular → «разовая помощь / каждые 28 дней» (как в UI).
2. **Минимальное участие.** Сначала проверить в `apps/api` и `packages/shared`, как используется сумма (`stake`,
   `minStake`, бюджет): на один сбор или в месяц. Одна формулировка везде — на экране Seed, в Профиле, на Сборе, в
   помощи. Если сумма на один сбор — убрать «в месяц». Отчитаться, что нашли.
3. **«Путь к просьбе».** Один компонент и один набор ключей вместо пяти (StartCard шаг 3, GrowStrip,
   PathToRequestSheet, лист на `AskPage`, PathCard на `AddPage`). Остальные места используют его.
4. **StartCard** (`components/circle/StartCard.tsx`): одна главная кнопка «Добавить человека», шаги — неинтерактивный
   чек-лист с галочками.
5. **Seed** (`pages/SeedPage.tsx`): ссылка «Назад» (на интро), значение по умолчанию предвыбрано, кнопка
   «Сохранить и продолжить» — один тап. Без «Пропустить», оставляющего сумму пустой.
6. «Обсуждение» как статус участия → «Вы участвуете» (ключи `collection.stageTalk`, `circle.feed.participating`,
   `OpenCollectionsPage`).
7. **Чипы колец** на Круге: смысл без интро — подпись или подсказка «рукопожатие» (уместить в 390 px), `aria-label`
   полным текстом.
8. **«Сеть может помочь»** в сцене (`NetStats.tsx`) — значок ⓘ, чтобы было видно, что нажимается.
9. **Добавить** при закрытой Просьбе: карточка ссылки первой, объяснение замка ниже.
10. «Отказаться» от участия → «Выйти из сбора».
11. **Экран сбора:** линейка этапов (`StageRail` из ui2) как в макете v2.
12. **Словарь:** лимит — везде «знакомства» («150 знакомств»), «Принять и связаться» → по словарю; один набор
    строк экрана человека (слить `circle.person.*` и `person.*`), «Имя в круге» везде; «Ваша сеть может помочь» одной
    фразой; в правовых текстах заменить только термины удалённых понятий («бюджет», «обязательства»), смысл
    документов не менять — спорное вынести в отчёт.
13. **Мёртвые ключи** (`milestones.*`, `retired.*`, `dashboard.period*`, `videoGuide.*`, `requiredInfo.*`,
    `settings.ignoreList`, `chat.topics` и любые другие без использования) — удалить из всех 28 локалей; перед
    удалением grep по `apps/` и `packages/` (включая бот в `apps/api`).

## Правила
- Изменённые и новые тексты перевести во все 28 языков (формы множественного числа по CLDR, как в WP8).
- Не трогать файлы WP16: `NativePushBootstrap.tsx`, `ChatAssistant.tsx`, `FaqPage.tsx`, `FaqScreen.tsx`,
  `SupportChatPage.tsx`, `BroadcastPanel.tsx`, `MessageComposer.tsx`, `BroadcastScreen.tsx`, `tailwind.config.js`.
- Только токены и ui2, тексты через локали.
