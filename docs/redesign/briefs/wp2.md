## Сделать
1. Круг: сцена с графом (до мерджа WP3 — текущий `NetworkGraph` как есть; после — пропсы `onNodeTap`, `highlightPath`,
   `hiddenRings`, `focusOnMe`, `theme`), карточка «Сеть может помочь» (сумма из `stats.networkCapabilities`, число
   людей, дельта за неделю), чипы колец с числами, кнопка «К себе».
2. Лента: строки из `notification.list` + `pending.incoming` + `pending.myPending` + `collection.myParticipating`
   (просьбы, заявки, подтверждения, новые циклы, закрытые сборы, вехи как строки), опрос `unreadCount` раз в 15–30 с,
   верхний баннер при новом событии, состояния «Тихо» и «Пусто» (первый организатор: три шага).
3. Лист знакомства (принять/отклонить заявку через `pending.accept` / `pending.reject`), карточка человека по тапу
   на узел (имя, кольцо, через кого; действия Сбор / Открыть / Контакты), лист «путь к просьбе» (два шага: «Ваш круг
   N из 5», «Сеть N из 10», имена одиноких связей, «Напомнить» через share).
4. Десктоп: сцена слева, лента 400 px справа, карточка человека занимает правую колонку с «‹ Лента».
5. Люди: поиск, тумблер колец, строки с «через кого», переход на экран Человека (WP5).
6. Удалить после переноса логики: `MilestonesCard`, `AcquaintanceCard`, `CloudBackground` с главной,
   `NotificationsPage`, `MyNetworkPage`.
7. Возврат на граф на то же место (screens.md §3): при уходе с Круга сохранить в стор `graphRef.getView()`, выделенный
   узел, путь и скрытые кольца; при возврате — `setView` без анимации появления. Работает и при «Назад» с экрана
   Человека, и после Сбора/Людей.
