# Спецификация экранов редизайна

Источник правды по виду экранов — интерактивный прототип [`mockups/app.html`](mockups/app.html)
(17 + 3 экрана, переключаются кнопками под телефоном). Этот документ описывает каждый экран словами:
что на нём есть, откуда берутся данные (tRPC-процедуры текущего API), какие состояния обязательны
и что считается готовым. Решения, из которых всё это следует, — в [ux-audit.md](ux-audit.md), разделы 5, 7 и 8.

Как открыть прототип: любой статический сервер из папки `docs/redesign/mockups`, например
`npx -y http-server docs/redesign/mockups -p 8787`, затем `http://localhost:8787/app.html`.
Кнопки под телефоном переключают экраны и состояния; тумблер «Тёмная тема» в Профиле включает тёмную тему.

## Общие правила

- **Цвета** только через семантические токены из `apps/web/src/styles/tokens.css`: `canvas`, `surface`, `surface-2`,
  `ink`, `ink-muted`, `ink-subtle`, `line`, `line-strong`, `care` (teal, основное действие и участие), `link`, `sos`, `warm`.
  Никаких `gray-*`, `blue-*`, hex-значений и `dark:`-вариантов — тему переключают токены.
- **Шрифт** Manrope 500/600/700. Заголовок экрана 32 px / −0.04em; заголовок карточки 22 px; текст 16–17 px;
  подпись 13–14 px `ink-muted`. Цифры — `font-variant-numeric: tabular-nums`.
- **Размеры**: поля ввода и основные кнопки 56 px высотой, радиус 16; карточки радиус 22, листы/диалоги 32;
  строки списка минимум 56 px; минимальная зона касания 44 px.
- **Один акцент**: `care` для основного действия и всего, что связано с участием; `sos` только для отказа,
  удаления и красной метки на табе «Просьба». Никаких градиентов и `shadow-lg`; у карточек одна мягкая тень.
- **Шапка пушевого экрана**: «‹ Название родителя» слева, заголовок по центру, опциональное действие справа.
  Корневые экраны (четыре таба) без кнопки «назад».
- **Листы и диалоги** — один компонент `Sheet` (скрим + панель снизу, радиус 32, появление снизу).
  Все подтверждения через него, не через `window.confirm`.
- **Строка события** — один компонент `EventRow`: иконка 36 px в квадрате `surface-2`, заголовок 16 px,
  подпись 13 px, шеврон. Используется на Круге и в списках.
- **Анимации**: переходы между экранами push/pop 400 мс, табы — fade; `prefers-reduced-motion` отключает всё.
- **Telegram Mini App**: от Telegram берём только светлую/тёмную схему (`colorScheme`), цвета — свои токены;
  `BackButton` Telegram работает как «назад» на пуш-экранах и как сворачивание графа на Круге.
- **Вехи**: «Первое рукопожатие» и «10 человек в круге» — строки в ленте Круга; при первом рукопожатии один короткий
  лист-поздравление (`milestone.markSeen`). Отдельной карточки нет.
- **Суммы**: везде только $ (`$` после числа: «80 $»). Валюты и курсы в интерфейсе не используются.
- **Словарь** (одно слово на понятие во всех 28 локалях): Круг · Рукопожатие (1-е / 2-е / 3-е) · Просьба · Сбор ·
  Участие · Минимальное участие · Подпись в круге · Чат сбора · Разовая помощь / Каждые 28 дней · Новый цикл.
  Не используются: Потенциал, Вехи, Намерение, Экстренный / Регулярный, Нужно, Уведомить, Заглушить, SOS (как слово).

## Навигация

| Таб | Экран | Пуш-экраны из него |
|---|---|---|
| Круг | Главная: числа, 3D-граф, чипы колец, лента событий | Люди (по чипу), Сбор (по событию), Человек (по узлу графа / из Люди) |
| Просьба | Карточка просьбы (доступна при 5 в 1-м кольце и 10 в сети, до этого — лист «путь к просьбе», см. §5) | — |
| Добавить | Ссылка, share, QR, сканер | QR, Считать |
| Профиль | Сгруппированный список | Аккаунт, Минимальное участие, Открытые сборы, Прошлые сборы, Помощь |

Онбординг вне табов: Приглашение → вход → Интро → Узел → Круг (пустое состояние).

Маршруты (предложение, менять вместе с `App.tsx`): `/` Круг · `/ask` Просьба · `/add`, `/add/qr`, `/add/scan` Добавить ·
`/me` Профиль, `/me/account`, `/me/stake`, `/me/open`, `/me/history`, `/me/help` · `/people/:ring` Люди ·
`/collection/:id` Сбор · `/person/:id` Человек · `/invite/:token` Приглашение · `/intro`, `/seed` онбординг.
Старые `/dashboard`, `/network`, `/notifications`, `/create`, `/settings` — редиректы на новые.

## 1. Круг (главная) — прототип «Круг», «Тихо», «Пусто», «Пуш»

**Назначение.** Увидеть свою сеть и всё, что требует внимания.

**Состав сверху вниз**
1. Бренд-строка: знак 28 px + «Social Organizer». Тонкая линия снизу.
2. Числа: слева «В сети N человек» (16 px bold) и подпись «Сеть может помочь»; справа сумма `X $` (20 px) и
   `(+Y $ за неделю)` цветом `care`. Тап по блоку открывает лист с объяснением: «Сумма минимального участия людей
   в вашей сети: 1-е, 2-е и 3-е рукопожатие».
   Данные: `connection.getNetworkStats` (totalReachable, byDepth), `stats.networkCapabilities` (total).
   Дельта за неделю — нового поля нет; до его появления скобку не показывать.
3. Сцена графа: существующий `NetworkGraph` из `@so/graph-3d` (см. ux-audit §8), занимает всё свободное место между
   числами и лентой. Данные: `connection.graphSlice`. Подсветка пути активного сбора: `connection.findPath`.
   Тап по узлу → Человек. Поверх сцены снизу:
   - чипы колец `● 9 1-е`, `● 5 2-е`, `● 2 3-е` — тап открывает Люди для этого кольца;
   - кнопка «К себе» (в `care`, когда камера ушла от центра) — возвращает камеру.
4. Лента событий (`EventRow`, до появления скролла помещается 3–4 строки, дальше скролл всего экрана):
   - **Просьба**: «Мария Коваль» / «Через Олег брат · разовая помощь» → Сбор. Источник: `notification.list`
     (типы новой коллекции), путь — `handshakePath`.
   - **Обсуждение**: «Мария Коваль» / «Обсуждение» — сборы, где я уже назвал сумму → Сбор. `collection.myParticipating`.
   - **Новый цикл**: «Денис Волков» / «Новый цикл · ваши 15 $ · до 12 апреля» → Сбор. Уведомления о продлении
     регулярного сбора (сейчас отдельная карточка с кнопками «Помню / Отозвать» — убирается, действия на экране Сбор).
   - **Новый человек**: «Катя Белова» / «Вошла в приложение» → лист знакомства (см. ниже). `pending.incoming`.
   - **Ждём подтверждения**: исходящая заявка, строка без действия → Человек. `pending.myPending`.
   Прочитанное исчезает из ленты (`notification.markRead` при открытии; `notification.dismiss` свайпом).
5. Таб-бар.

**Состояния**
- *Пусто* (0 связей): вместо графа — знак и имя пользователя, карточка «Просьба идёт по подтверждённым рукопожатиям.
  Пока рядом никого, сигналу идти некуда» с тремя шагами (Профиль → Аккаунт; Первый человек → Добавить; Пять человек
  «0 из 5» → Добавить) и кнопка «Добавить человека». Числа показывают «В сети 0 человек · 0 $».
- *Тихо*: граф есть, событий нет — текст «Пока тихо. Просьбы, новые люди и циклы сборов появятся здесь».
- *Пуш*: при приходе события в открытом приложении сверху выезжает баннер (знак, «Social Organizer», заголовок,
  подпись), тап открывает событие, через 5 с уходит сам; строка в ленте появляется с анимацией.
- Загрузка графа: скелет сцены и числа из кэша (`useCachedNetworkStats`), граф появляется без «прыжка».

**Лист знакомства** (из события «Вошла в приложение»): заголовок — имя, подпись «Вошла в приложение по вашей ссылке»,
кнопки «Мы знакомы» (`care`) и «Мы не знакомы» (вторичная). После «Мы знакомы» тот же лист показывает поле
«Подпись в круге» с предзаполненным именем и кнопку «Готово» (`pending.accept` + `connection.setNickname`).
«Мы не знакомы» → `pending.reject`, строка уходит.

**Готово, когда**: с тестовым аккаунтом `anna@test.local` экран показывает 18 человек, граф, три чипа, ленту
из просьбы Марии, заявки Кати и открытого сбора; пустой аккаунт `new@test.local` видит состояние «Пусто»;
все числа и строки берутся из API, не из моков.

## 2. Люди — прототип «Люди»

**Назначение.** Список людей одного кольца; замена аккордеону «N-е рукопожатие».

Шапка «‹ Круг · 1-е рукопожатие». Поле поиска (56 px, `type=search`). Строка-тумблер «Показывать на графе · 9»
(скрывает кольцо на сцене, состояние хранится локально). Список строк: подпись в круге жирным, под ней — имя аккаунта,
если подпись отличается, или «через Олег брат → …» для 2–3 кольца. Тап → Человек.
Данные: `connection.list` (1-е), `connection.graphSlice` (2–3 с путём). Пустое: «Пока никого» / «Никого не нашли».
Сортировка: по дате появления в сети, новые сверху.

## 3. Человек — прототип «Человек»

Шапка «‹ Круг» (или «‹ Люди», «‹ Сборы» — откуда пришли). Карточка: фигура пути (точки Анна — Олег брат — Мария,
последняя обведена `care`), имя 22 px, для 1-го кольца — поле «Подпись в круге» (сохраняется при уходе с экрана,
`connection.setNickname`) и «Аккаунт: Олег Ким»; для 2–3 кольца — «2-е рукопожатие · через Олег брат».
Контакты (если человек их открыл, `user.getContacts`): пилюли под карточкой, каждая открывает внешний мессенджер
или сайт (`buildContactUrl`). Личных сообщений внутри приложения нет и не планируется: карточка человека на Круге
и этот экран предлагают «Контакты», а не «Написать».
Ниже «Прошлые сборы» этого человека: карточки с кольцом-прогрессом, «через кого», дата, «44 из 80 $» (`stats.helpHistory`).
Для 1-го кольца внизу текстовая кнопка «Убрать из круга» → лист «Убрать Олега из круга?» / «Убрать» (`sos`) /
«Оставить» (`connection.revoke`). Для не связанного человека (пришли по ссылке на профиль) — кнопка
«Мы знакомы» (`pending.sendDirectRequest`) и состояние «Заявка отправлена».

## 4. Сбор — прототип «Сбор», «Открытые»

Шапка «‹ Круг» (или «‹ Сборы»); справа — красный текст «Отказаться» только если я уже участвую.
Карточка сбора, три слоя и не больше: фигура пути до автора (только у участника; у автора путь из одной точки не
показывается); имя автора 22 px с подписью «Разовая помощь · 2 дня назад» или «Каждые 28 дней · 3-й цикл» (без
«через кого»: это уже сказала фигура пути); шкала с легендой «Собрано Y $ · Цель Z $», а когда я участвую —
«Вы X $ · Другие Y $ · Цель Z $» (мой сегмент `ink`, остальные `care`); у участника одна строка «Сбор закрывает
Мария. Сумма может не дойти до цели». Рельсы стадий «Сумма · Обсуждение · Закрыт» нет: стадию показывает нижняя
карточка, рельса её дублировала.
Нижняя карточка по состоянию: поле «Ваша сумма» (money, предзаполнено минимальным участием) с подсказкой «Минимальное
участие — 15 $. Можно больше» и кнопкой «Участвовать» (`obligation.create`); если участвую — сумма крупно, «Изменить»
(`obligation.updateAmount`), кнопка «Открыть чат сбора» (внешняя ссылка, любой мессенджер) и одна фраза «Как передать
деньги, договариваются в чате. Приложение это не фиксирует». Ошибка инлайн «Минимум 1».
«Отказаться» → лист «Отказаться от участия?» / «Отказаться» (`sos`) / «Остаться» (`obligation.unsubscribeFromCollection`).
Регулярный сбор, новый цикл: в шапке подсказки нет; тёплая плашка «Новый цикл до 12 апреля. Подтвердите участие, иначе
15 $ не войдут в этот цикл», кнопки «Подтвердить 15 $» и «Другая сумма»; в списке участников подписи «подтвердила» /
«ждём вас».
Закрытый сбор (из «Прошлых сборов»): подпись «закрыт 12 марта», шкала с итогом, список участников, действий нет;
отдельной карточки «Вы участвовали» нет, она повторяла шкалу.
Данные: `collection.getById`, `connection.findPath`, `obligation.myList`.

**Автор сбора** видит тот же экран, но: без пути и без подсказки о закрытии; вместо поля суммы — список участников (имя, сумма, отметка «переведено»
через лист «Подтвердить перевод от Олега?»), «Чат сбора» редактируется по тапу, кнопка «Закрыть сбор» внизу текстом
→ лист подтверждения (`collection.close`), «Поделиться сбором» через системный share и кнопка QR (лист с кодом и
«Скачать для печати», как сейчас `QRCodeCanvas` 1024 px). Ссылка и QR ведут на **публичную страницу сбора**
`/sos/:id` (`buildSosInviteUrl`), подпись под кнопками предупреждает, что страница публичная и присоединившийся станет
1-м рукопожатием без подтверждения: «Страница сбора публичная: имя, сумма и прогресс видны всем. Кто войдёт по ссылке,
станет вашим 1-м рукопожатием».

**Публичная страница сбора** (`/sos/:id`, без входа, сейчас `SosLandingPage`, данные `collection.getPublic`):
бренд без слогана, аватар, «Анне нужна помощь», одна строка «Разовая помощь · открыт 2 дня назад», карточка «100 $ из 300 $»
с полосой и строкой «4 участника · деньги передают лично», плашка «Вы станете частью круга Анны. Присоединяясь, вы подтверждаете, что знаете её лично», одна кнопка
«Присоединиться» с одной строкой «Дальше вход: Apple, Google, Telegram или почта» (вход на следующем шаге; в Telegram — `startapp=sos_<id>`, в браузере — `/login?redirect=`
на `/collection/:id?sos=true`). После входа `invite.acceptSos` создаёт прямую связь с автором без подтверждения и
открывает Сбор в состоянии «новая просьба»; автору в ленту приходит «Катя вошла по ссылке сбора». Закрытый сбор —
та же страница без кнопки, со строкой «Сбор закрыт». Автор может убрать присоединившегося по ссылке человека из
круга одним действием из списка участников (лист подтверждения, `connection.revoke`).
Макеты: `mockups/v2/collection.html`, экраны 4, 5, 6.

**Приостановлен (BLOCKED).** Статус ставит только администратор: процедура `collection.block({ id, reason })` с причиной
из списка («Жалобы участников», «Подозрение на мошенничество», «Нарушение правил», «По просьбе автора»), снимает
`collection.unblock`. Участник видит ту же карточку сбора с плашкой «Сбор приостановлен», без поля суммы, кнопки участия
и ссылки на чат; строки ленты про этот сбор не приходят. Автор видит плашку с причиной и кнопкой «Написать в поддержку»
(Помощник). Админ на экране сбора видит в шапке действие «Приостановить» / «Возобновить» с листом выбора причины.
Цель сбора обязательна (минимум 10 $); старые сборы без цели показывают «Цель не задана», и автор задаёт её при первом
открытии.

**Открытые** (из Профиля): шапка «‹ Профиль · Открытые», карточки «Денис Волков / Обсуждение / шкала» → Сбор.
Пусто: «Открытых сборов нет». Данные: `collection.myParticipating` + `collection.myActive`.

## 5. Просьба — прототип «Просьба»

**Доступ («путь к просьбе»).** Просьбу можно отправить, когда выполнены оба условия: в 1-м рукопожатии не меньше
**5** человек и в достижимой сети (1–3 кольцо) не меньше **10**. Пороги — константы конфигурации сервера, проверка
в момент `collection.create`, без постоянного флага (сеть может и сжаться). Пока условия не выполнены:
- таб «Просьба» приглушён, вокруг знака тонкое кольцо прогресса (меньшая из двух долей). Замка нет: это путь, не запрет;
- тап по табу (и прямой переход на `/ask`) поднимает лист поверх Круга: заголовок «Ещё немного, и просьбу услышат»
  (при 0 связей — «Просьба откроется, когда рядом появятся люди»), строка «Просьба идёт по рукопожатиям: сначала к вашим
  людям, потом к их людям», два шага с полосами: **«Ваш круг · N из 5»** с подсказкой про ссылку и QR и
  **«Сеть · N из 10»** с именами прямых связей, у которых пока никого нет («Катя пока одна в сети…»), и кнопкой
  «Напомнить» (системный share с коротким текстом); ссылка «Как это выглядит» раскрывает предпросмотр карточки просьбы;
  кнопка «Добавить человека»; «Позже». Макет: `mockups/v2/circle-a.html`, состояние «Просьба закрыта»;
- когда оба числа набраны: таб становится обычным без перезагрузки, в ленту приходит строка «Просьба открыта».
После открытия сумма первой просьбы ограничена двукратным «Сеть может помочь» (константа множителя на сервере);
при превышении — инлайн-ошибка «Сейчас сеть может собрать до N $». Это заменяет текущую модалку «Недостаточно связей».
Данные: `connection.getNetworkStats` (byDepth[1], totalReachable), для имён одиноких связей — `connection.list` с
`connectionCount`.

Заголовок «Просьба» 32 px. Одна карточка: подпись «Сколько нужно», сумма 52 px без рамки (inputmode numeric,

## 6. Добавить — макеты `mockups/v2/add.html`

Единственный экран приглашения. Два правила: ссылка, отправленная куда-то, требует подтверждения знакомства

подсказка с двумя правилами. Ниже группа «Пришли по вашей ссылке · N»: первым — человек, которого надо подтвердить
(«подтвердите знакомство», тап → лист «Мы знакомы / Не знакомы»), остальные с датой входа в круг → Человек.

**Начало пути**: пока Просьба закрыта, над карточкой ссылки — «Ваш круг N из 5», «Сеть N из 10» и подсказка, кому
напомнить (те же данные, что в листе «путь к просьбе»). Исчезает, когда оба числа набраны.

**Мой QR** (пуш-экран «‹ Добавить · Мой QR»): QR 200 px в белой карточке, вокруг кольцо-таймер, под ним «0:50»,

и «Готово». Бэкенд: одноразовый токен с TTL 60 с на базе `InviteLink` (`invite.generate` с `ttl`), приём такого токена
создаёт связь как подтверждённую без `pending` и возвращает имя для листа результата.

**Считать**: камера на весь экран, уголки видоискателя `care`, подсказка с двумя правилами, внизу «Показать мой», крестик
закрывает. Веб: `getUserMedia` + `BarcodeDetector`, фолбэк на JS-декодер; Capacitor: плагин сканера, запрос разрешения,
состояние «Нет доступа к камере» с переходом в настройки. Распознано: живой токен → лист результата; постоянная ссылка →
`/invite/:token` (заявка с подтверждением); ссылка на сбор `/sos/:id` → публичная страница сбора.

**Результат** (лист поверх камеры): «Катя Белова · Теперь ваше 1-е рукопожатие», плашка «Знакомство подтверждено
с обеих сторон», поле «Подпись в круге» с предзаполненным именем (`connection.setNickname`), «Готово». Для постоянной
ссылки — «Заявка отправлена. Катя подтвердит знакомство» без поля подписи.
