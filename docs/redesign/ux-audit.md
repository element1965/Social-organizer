# UI/UX-аудит: текущее приложение и макеты редизайна

Дата: 2026-11-08. Ветка `redesign`.
Цель редизайна: простое, не перегруженное, интуитивное и современное приложение.

Что сравнивалось:

- **Текущее приложение** — локальная сборка `apps/web` с тестовыми данными (`seed-dev.ts`, аккаунт Анны: 6 прямых связей, сеть из 18 человек), просмотр всех экранов в браузере плюс инвентаризация кода 17 файлов страниц и компонентов.
- **Макеты** — интерактивный прототип `app.html` (17 экранов, 4 таба) и концепт лендинга `hui.html`. Лежат вне git в `local/mockups/` (копия с `D:/MacDrop/DEV/social-organizer/docs/mockups/`).

---

## 1. Резюме

1. **Главная беда текущего UI — не стиль, а избыточность.** На главной четыре входа в «пригласить», три разных числа про размер сети, две кнопки помощи; в настройках 13 карточек и 25+ контролов; создание сбора — форма плюс статистика плюс два списка плюс цепочка из 2–3 модалок. Пользователь не понимает, что здесь главное.
2. **Макеты решают именно это.** Четыре таба (Круг, Просьба, Добавить, Профиль), один граф вместо «списка + 3D + графика роста», одна пара чисел («В сети 16 человек» / «Сеть может помочь 86 $»), одна карточка на просьбу, один экран для приглашения, профиль списком. Структуру макетов стоит принять как целевую.
3. **Макеты нужно дополнить, а не копировать один в один.** В них нет мест для обязательных вещей (выход, язык, юридические ссылки, помощь/FAQ, подключение Telegram, админские инструменты), не решён масштаб графа при 50+ людях, есть разнобой слов для одного действия (Просьба / SOS / Обратиться / Отправить), и красная «Удалить аккаунт» стоит прямо на вкладке Профиль.
4. **Визуальная система в макетах правильная**: один акцент (teal), один «опасный» цвет, чернильный текст, светлая канва, карточки без градиентов, крупные поля 56 px, Manrope. Это совпадает с уже внесёнными токенами `tokens.css`. Текущее приложение использует токены только в `Layout.tsx`, остальные 16 файлов — сырые `gray-*/blue-*`, градиенты, `shadow-lg`, 30+ hex-значений.
5. **Порядок работ**: сначала структура (навигация, главная, просьба, профиль), потом визуал, потом онбординг. Детали — в разделе 6.

## 2. Текущее приложение: что мешает

### 2.1 Главная (`/dashboard`)

Экран без главного действия. Сверху-вниз: шапка с аватаром и подписью «Настройки» (дублирует таб), кнопка Telegram-чата, кнопка «?»; карточки «Сеть 18» и «Потенциал $330»; карточка «Моя сеть 6» (красным, потому что < 30 — порог нигде не объяснён); кнопка «Пригласить»; QR-код; карточка «Вехи» с прогрессом «6 из 10».

- Три числа про одно и то же: «Сеть 18», «Моя сеть 6», «6 из 10». Пользователь не знает, какое важно.
- «Пригласить» доступно четырьмя способами: кнопка, QR, карточка-гейт при пустой сети, «Пригласить знакомого» в карточке знакомства. Реализовано тремя разными компонентами (ShareSheet, InvitePopup, InviteBlock).
- «Потенциал $330 — заявлено участниками» — термин не объяснён, карточка не кликается.
- Два «?» на экране (свой на главной и общий в Layout), ещё и Telegram-чат сообщества в шапке за дополнительным попапом.
- Нет ни одного события: ни входящей просьбы, ни заявки на знакомство — они живут в другой вкладке.
- Фоном лениво грузится 3D-облако частиц с прозрачностью 30 % — декор без функции, но с ценой по производительности.

### 2.2 Навигация

Пять табов: Главная, Уведомления, SOS, Сеть, Настройки.

- «Уведомления» и «Сеть» — две вкладки для того, что в макете укладывается на одну главную (события под графом).
- «SOS» в центре ведёт на экран с заголовком «Нужно», кнопкой «Уведомить» и переключателем «Экстренный / Регулярный». Четыре разных слова для одной сущности.
- Нет кнопки «назад» на страницах Профиль человека, Сбор, FAQ, Поддержка — только системный back.
- FAQ, Помощник и чат поддержки спрятаны за «?».

### 2.3 Уведомления

Экран смешивает четыре вещи: «Экстренные сигналы», ленту уведомлений (те же экстренные сборы показаны второй раз), «Входящие заявки» и «Ожидает подтверждения». Самое действенное — входящая заявка на знакомство — стоит последним и управляется иконками ✓/✗ без подписей. Бейджи типов — сырые ключи (`NEW_OBLIGATION`). «Закрыть все» серым на тёмном почти не видно.

### 2.4 Создание сбора (`/create`)

- Один экран: форма, видеоинструкция (показывается всегда, даже для «Экстренного»), «Статистика поддержки» с полукругом, «Мои сборы», список «Помог». Слово «Помог» используется для трёх разных вещей (подпись диаграммы, заголовок списка, счётчик в профиле).
- После «Уведомить» — до трёх модальных подтверждений подряд («Недостаточно связей», «Это настоящий сигнал», «Подтвердите создание» с чекбоксом) плюс ещё чекбокс для сумм > $10 000. При этом **закрытие** сбора подтверждения не требует.
- Статус сбора выводится как `ACTIVE`, не переведён.

### 2.5 Сеть (`/network`)

- Два представления одних данных (список-аккордеон и 3D-глобус) и график роста, который при 6–20 людях — горизонтальная линия.
- Подсказка в 3D: «ЛКМ: вращение, Колёсико: масштаб, ПКМ: перемещение» — в мобильном приложении и Telegram Mini App. Подпись «GoodWill Net», легенда «You / 1° / Online» — не переводятся.
- Три цвета колец (синий, зелёный, оранжевый) конфликтуют с одно-акцентной палитрой; цифры «2 / 3 / 4» справа у людей — число их связей красным, без пояснения.

### 2.6 Настройки

13 карточек, 25+ контролов, один длинный скролл: профиль, 10 полей контактов (Telegram, WhatsApp, Facebook, Instagram, X, TikTok, LinkedIn, VK, e-mail, сайт), «Заявлено на месяц», блок приглашения с абзацем про персональный ID, «Язык» и «Голос ассистента» в одну строку, тема, звуки + push в одну строку, два тумблера напоминаний, размер шрифта, Telegram, «Связать аккаунт» (тултип говорит «Скоро», кнопка работает), «Выйти», «Удалить аккаунт».

Это не настройки, а свалка всего, что не поместилось на другие экраны.

### 2.7 Сбор, Профиль человека, Вход

- Сбор: смешаны «$» и «USD»; владелец делится ссылкой только копированием; подтверждение оплаты — иконка без текста.
- Профиль: действие «Заглушить» с иконкой выключенного звука на самом деле **разрывает связь** через `window.confirm`.
- Вход: до шести способов на одном экране (Google, Apple, Telegram-виджет/кнопка, e-mail-код, e-mail-пароль, «Есть код из Telegram-бота»). Экран всегда тёмный независимо от темы.

### 2.8 Визуальная система

| Что | Факт |
|---|---|
| Семантические токены | только `Layout.tsx`; в 16 остальных файлах 0 использований, 1 000+ сырых классов `gray-*/blue-*` с `dark:` |
| Градиенты | аватар blue→purple, карточки blue→purple, green→emerald, blue→indigo; вход и лендинг — тёмные градиенты |
| Hex в коде | ~30: цвета глубин, легенда, бренды в ShareSheet, два разных Telegram-синих (#26A5E4 и #2AABEE) |
| Тени | `shadow-lg` на круглых кнопках шапки и пилюлях помощи, `shadow-xl` на модалках, teal-свечение на CTA лендинга |
| Модалки | пять разных самодельных реализаций; только VideoGuide через портал и с Escape |
| Непереводимые строки | SOS, FAQ, GoodWill Net, легенда, «5m/3h/2d», admin, App Store, Privacy Policy / Terms |

### 2.9 Плотность: число действий на экране

| Экран | Сейчас | В макете |
|---|---|---|
| Главная | ~9 кнопок + 5 табов | 3 чипа колец, «К себе», граф, 1–3 события, 4 таба |
| Создание / Просьба | 8 контролов + 2–3 модалки + 2 списка | сумма, 2 сегмента, ссылка, «Отправить» |
| Сеть | 3 кнопки шапки, аккордеон, 3D, график | — (влилось в Круг) |
| Уведомления | 4 блока, иконки ✓/✗ | — (события под графом, пуш → лист «Мы знакомы / Не знакомы») |
| Настройки / Профиль | 13 карточек, 25+ контролов | 8 строк в 5 группах + 1 кнопка |
| Аккаунт | 10 полей контактов | 5 полей + «Ещё контакт» |

## 3. Макеты: что они делают правильно

1. **Четыре таба и одна точка входа на задачу.** Круг — увидеть сеть и события. Просьба — попросить. Добавить — расширить круг (ссылка, QR, сканер). Профиль — я, участие, сборы, настройки. Ничего не дублируется.
2. **Граф как главная.** 2.5D-граф с кольцами 1-е/2-е/3-е, чипами-фильтрами и кнопкой «К себе». Активный сбор подсвечен на графе (путь Анна → Олег → Мария teal-линией). Это одновременно «моя сеть», «путь связи» и «что происходит».
3. **Одна пара чисел**: «В сети 16 человек» и «Сеть может помочь 86 $ (+12 $ за неделю)». Вместо «Сеть / Потенциал / Моя сеть / Вехи».
4. **Лента событий под графом**: «Мария Коваль — через Олег брат · разовая помощь», «Денис Волков — Обсуждение», «Катя Белова — вошла в приложение». Один формат строки для просьбы, открытого сбора и новой регистрации.
5. **Просьба в одной карточке**: крупная сумма, сегмент «Разовая помощь / Каждые 28 дней», ссылка на чат, одна подсказка («Сначала сигнал получат люди, которых вы знаете»), «Отправить». Ошибки инлайн («Минимум 10», «Нужен чат сбора»), без модалок.
6. **Экран сбора**: путь (кто через кого), стадии «Сумма → Обсуждение → Закрыт», шкала «Вы / Другие / Цель», одно поле, одна кнопка. Отказ — красная пилюля в шапке с листом подтверждения.
7. **Профиль как сгруппированный список** в духе iOS Settings: Участие (Сеть может помочь, Минимальное участие), Сборы (Открытые, Прошлые), Тёмная тема, Уведомления (свёрнуты). Аккаунт — отдельный экран с 5 полями и «Ещё контакт».
8. **Знакомство через пуш**: баннер «Катя Белова — Вошла в приложение» → лист «Мы знакомы / Мы не знакомы» → поле «Подпись в круге» (личная метка «Олег брат» вместо никнейма). Понятнее иконок ✓/✗.
9. **Онбординг**: приглашение («Олег Ким зовёт вас» + 3 кадра идеи + 3 кнопки входа) → интро из 4 кадров с «Пропустить» → «Узел» (минимальное участие) → пустой Круг с тремя шагами (Профиль, Первый человек, Пять человек).
10. **Визуал**: одна палитра (`--ink`, `--teal`, `--danger`, `--canvas`, `--paper`), тёмная тема теми же переменными, радиусы 16/22/32, поля 56 px, Manrope, `prefers-reduced-motion` учтён, фокус-кольца есть.
11. **Лендинг `hui.html`**: одна метафора (круг из шести знакомых, «хуэй»), интерактивный круг по месяцам, две схемы (поручительство, новый человек). Короче и понятнее шести абзацев текущего лендинга.

## 4. Макеты: пробелы и риски

### 4.1 Структурные

- **Нет места для обязательного.** Выход из аккаунта, язык (28 локалей), Политика и Условия (требование сторов), помощь/FAQ/ассистент, чат сообщества, подключение Telegram и «Связать аккаунт», push-разрешение, админские инструменты (рассылка, кластеры, статистика). Предложение: группа «Ещё» в Профиле — Язык, Помощь, О приложении (условия, политика, открытый код), Выйти; админская группа видна только админам.
- **«Удалить аккаунт» — красная кнопка прямо на вкладке Профиль.** Самое опасное действие не должно быть самым заметным. Перенести в конец экрана Аккаунт текстовой кнопкой.
- **Граф при масштабе.** В макете 9 прямых + 7 дальних. У активных пользователей прода может быть 30+ прямых и сотни на 2–3 кольце — подписи и узлы сольются. Нужны: автоскрытие колец 2–3 при N > порога, список-режим (тап по чипу «9 1-е» → лист со списком людей), поиск по имени. Проверить на реальном распределении связей из прод-БД, когда появится доступ.
- **Лента событий — только «сейчас».** Нет прочитанных/прошлых событий, нет пустого состояния («Пока тихо»), не ясно, куда девается закрытый сбор и отклонённая заявка. Нужен экран «История» или раскрытие ленты.
- **Нет экранов ошибок/загрузки/оффлайна** и нет состояния «сбор закрыт» для участника.

### 4.2 Семантика и слова

- Одно действие названо четырьмя словами: таб **Просьба** с иконкой **SOS**, заголовок **Обратиться**, кнопка **Отправить**. Оставить «Просьба» в табе и заголовке, кнопку назвать «Отправить просьбу»; иконку SOS заменить на нейтральную или оставить только как цветовой акцент.
- «Сеть может помочь 86 $» — нужно одно касание до объяснения, из чего складывается (сумма минимальных участий достижимых людей?). Иначе цифра выглядит как обещание.
- «Минимальное участие 1 $» по умолчанию — объяснить, что это значит для человека, один раз, на экране «Узел».
- Стадии сбора «Сумма / Обсуждение / Закрыт» описывают моё участие, а не состояние сбора. Для автора сбора стадии другие. Разделить или переименовать («Вы назвали сумму → Вы в чате → Сбор закрыт»).
- «Разовая помощь» vs «Каждые 28 дней» — в проде есть циклы, напоминания за 3 дня, «Заявлено на месяц». Нужно решить, равно ли «Минимальное участие» текущему месячному бюджету, и что происходит с напоминаниями.

### 4.3 Поток «Просьба»

- Ссылка на чат обязательна до отправки. Человек в беде сначала должен создать группу в Telegram. Варианты: сделать поле необязательным (добавить ссылку позже на экране сбора) или создавать чат автоматически через бота.
- Нет подтверждения вообще. Одно короткое подтверждение («Отправить просьбу на 80 $ 16 людям?») оправдано — но одно, не три.

### 4.4 Доступность и эргономика

- Подписи табов 10 px, подписи на графе 10–11 px, зоны касания узлов 8–20 px радиуса — ниже рекомендуемых 44 px. Таб-бар поднять до 11–12 px, у узлов расширить невидимую зону тапа (в макете есть `hit`, увеличить минимум до 22 px).
- Приглушённый текст `#5c6d68` на `#f3f6f4` — контраст ≈ 4.9:1, проходит AA; на тёмной теме `#93a59f` на `#121917` ≈ 7:1. Ок.
- Красная пилюля «Отказаться» в шапке сбора — опасное действие рядом с «назад». Лучше вниз, под основную кнопку, текстом.
- Макет только телефонный. Веб-версия на десктопе сейчас — колонка `max-w-md` по центру; для редизайна это приемлемо, но граф на широком экране стоит дать шире.
- Telegram Mini App: у Telegram свой нижний бар и кнопка «назад»; таб-бар макета нужно проверить с safe-area и `BackButton` TG.

### 4.5 Добавить

- Три метрики («Добавлены в сеть 3», «Открыли ссылку 8», «1-й круг добавил 5») — вторая и третья тщеславные, первая полезна. Оставить одну-две.
- «Считать» (сканер QR) — новая возможность: в вебе нужен `getUserMedia`, в Capacitor — плагин камеры и разрешение. Оценить как отдельную фичу, не блокировать ею редизайн.
- «Поделиться» в макете только копирует. В проде нужен системный share (Web Share API / Capacitor Share), а не семь брендовых кнопок как в текущем ShareSheet.

## 5. Целевая структура

```
Круг (главная)
  шапка: В сети N человек · Сеть может помочь X $
  граф 1–3 кольца, чипы колец, «К себе»
  лента событий: просьба / обсуждение / новый человек / заявка
  → Сбор (путь, стадия, шкала, моя сумма, чат)
  → Человек (путь, подпись в круге, прошлые сборы)

Просьба
  сумма · разовая / каждые 28 дней · чат (необязателен) · отправить

Добавить
  ссылка + системный share · QR · сканер · «добавлены в сеть N»

Профиль
  Я (аккаунт: имя, фамилия, телефон, почта, telegram, ещё контакт)
  Участие: сеть может помочь · минимальное участие
  Сборы: открытые · прошлые
  Настройки: тема · уведомления (свёрнуто) · язык
  Ещё: помощь (FAQ, ассистент, чат сообщества) · о приложении · выйти
  [админ]: рассылка · статистика
  Аккаунт → внизу: удалить аккаунт (текстом, с листом подтверждения)

Онбординг
  Приглашение (кто зовёт, 3 кадра, вход) → Интро (3–4 кадра, пропустить)
  → Узел (минимальное участие) → Круг с тремя шагами
```

Словарь (одно слово на понятие, везде): Круг · Рукопожатие (1-е / 2-е / 3-е) · Просьба · Сбор · Участие · Минимальное участие · Подпись в круге · Чат сбора · Разовая помощь / Каждые 28 дней.
