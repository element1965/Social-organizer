## Project writing skills

The project's Claude Code skills (how the project is told, explained and reviewed) are kept by the maintainers outside the repository.

| Skill | Use |
|---|---|
| `so-story` | Explain the project in landing copy, posts, onboarding, FAQ and assistant responses |
| `so-trust-lens` | Review changes against the three trust conditions: repeat interactions, mutual benefit and clear communication |
| `so-explainer` | Teach by play and prediction, including the landing explainer and `/how` |
