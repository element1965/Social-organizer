# Packaging

The plan of the packaging work, landing concepts and ideas waiting for a decision.

- [Idea — a "How It Works" video (from the brainstorm, not started)](how-it-works-video-idea.md) — The brainstorm's proposal for a 2–3 minute practical video complementing the published "Direct Mutual Support Through Real Connections" — its plot, principle and scope — recorded as an idea; no task has been given.
- [Landing concept "The flock and the seed" (prototype)](landing-concept-flock.md) — The landing concept the user chose on 2026-11-18 — a starling flock (no leader, each bird watches a few neighbours, a wave passes neighbour to neighbour) as the picture of the network and frost growing from one seed as the picture of growth past a threshold, with the process itself explained plainly — as a ten-screen landing plan, the final Russian copy, two code interactives, the generated media and how to port it into apps/web.
- [Landing concept "The network that is already there" (proposal)](landing-concept-lights.md) — A new landing concept after the user rejected both chat concepts — the network shown as light that is already there, two layers (life on video, the network as a graph), the visitor inside Maria's 48-hour story with one honest decision, a role flip and the next stage — with the analysis behind it, the screen plan, the visual system, the tech, a Higgsfield shot list and the open decisions.
- [Landing concepts from the brainstorm (not decided)](landing-concepts.md) — Two brainstorm proposals for the new landing — "The World Is Already Connected" (five scenes around the real 3D graph in a demo mode) and the "one life situation, three moving steps" first screen from the landing-references chat — with the corrections they need against the live app and our rules.
- [Packaging plan — from the data pool to the landing and in-app teaching](packaging-plan.md) — The agreed order of the packaging work (collect the pool → distil what matters → redesign the landing and web → in-app teaching) and which project and installed skills serve each stage.
